Usage guide

Use a reference swatch in the slicer

Open the detailed guide (Markdown)
Choose by appearance, then copy the recipe. Each A-number links directly to that color reference; enter only its F1-F4 labels and percentages in Color Mixing.
  1. Set the input colorsConfigure F1 Cyan, F2 Magenta, F3 Yellow, and F4 Grey in this exact slot order.
  2. Choose a tile visuallyBrowse the reference and additional color recipes, then read the participating F-slots and percentage recipe.
  3. Create the recipeClick + beside Color Mixing. Use Ratio for two- or three-filament colors and Cycle for four-filament colors.
  4. Apply and checkClick OK, assign the new color mix, slice, use the preview to confirm its assignment, and make a small test print before a production part.
Example - reference A5: select F1 and F2 in Ratio mode and set both to 50%.

Within each recipe group, swatches follow a continuous perceptual color path that minimizes visible jumps between neighbors. This catalog is a visual planning reference; filament, print settings, part geometry, lighting, and the display can all affect the final appearance.
