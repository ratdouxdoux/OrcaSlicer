# 颜色校准色板测试计划

## 目的

本测试计划用于测量四种已知颜色和透射距离（TD）的源耗材如何影响混合打印后的侧面可见颜色。

数据集应能够根据以下因素建立颜色模型：

- 源耗材颜色和 TD 值
- 双色、三色和四色混合比例
- 层高
- 混合模式：普通模式、Local Z、Local Z 加直接多色求解器
- 打印色板深度
- 测量背衬和照明条件

第一优先级是反射式侧面测量。背光/透射式测量也有价值，但它回答的是另一个光学问题，应作为独立数据集处理。

## 核心规则

每个色板都应作为致密的光学样片打印。

- 从侧面测量，不从顶部测量。
- 使用足够多的墙/外壁数，使色板完全填实。
- 避免稀疏填充、内部空洞或空气间隙。
- 打印测试盘前，确认预览/G-code 显示为致密实体。
- 保持喷嘴、温度、速度、冷却、挤出校准和耗材干燥状态一致。
- 尽可能使用分光测色仪定位夹具，并始终测量同一侧、同一位置。
- 如果无法使用夹具，应尽量保持测量几何可重复，并遮挡样品周围的杂散光，尤其是较薄样片。
- 每个色板进行多次读数，通常至少 3 次，并在可用时保存原始光谱数据。

内部空洞预计会改变散射行为，从而改变颜色。带有空洞的色板很可能无法代表真实材料混合效果。

## 可追溯性和盘面命名

每个打印盘都应具有可读标题和唯一的盘/运行标识。

推荐盘 ID：

- `P-1`
- `P-2`
- `P-3`

打印在盘面上的标签和 manifest 标题应包含：

- 盘/运行 ID
- 耗材组名称
- 源耗材槽位
- 源耗材卷轴标识
- 材料族
- 层高
- 色板深度
- 混合模式
- 如果一个测试集跨多个盘，则包含盘号

每个物理卷轴都应写上或贴上清晰标识。建议使用稳定 ID，例如：

- `C1`、`M1`、`Y1`、`W1`
- `R2`、`Y2`、`B2`、`K2`
- `PLA-CYAN-HITD-01`

卷轴 ID 应记录在 manifest 备注或测试日志中。不要只依赖“青色”或“白色”这类颜色名称；两卷看起来相似的耗材可能具有不同 TD 和颜料行为。

移除任何色板前，应从上方拍摄整盘照片，并确保盘面标签可见。如果某个色板意外移动，这张照片可以用于恢复顺序。

每个色板只应打印一个紧凑编号，例如 `A37`。盘面标签也应显示同一个字母，例如 `Plate A 1/1`。字母表示板/批次编号，并且每次打印都必须唯一。数字表示 manifest 中的样品行。这个紧凑编号应刻在色板背面侧壁靠近底边的位置，保证可见，同时避开主要测量区域。完整的耗材槽位、比例、颜色、TD 值、层高、深度和模式应以 manifest 为准，而不是依赖打印在色板上的文字。

## 切片器设置确认

校准窗口中的 Local Z 和直接多色字段应视为测试元数据和确认标记。

切片前，应手动确认实际打印设置与预期测试一致：

- 普通模式下，`Subdivide Mix Layer` 应关闭。
- Local Z 模式下，`Subdivide Mix Layer` 应开启。
- Local Z 加直接多色模式下，`Subdivide Mix Layer` 和 `Use direct multicolor Local-Z solver` 都应开启。

不要只依赖校准窗口中的复选框或 manifest 标签。切片预览、项目设置和生成的 G-code 才是实际打印内容的依据。

还应确认：

- 墙/外壁数足以填满色板。
- 稀疏填充没有产生内部空洞。
- 擦料塔位置不会与色板或定位夹具碰撞。
- 切片前，预期的耗材槽位和混合耗材定义已经存在。
- 盘面标签与实际打印设置一致。

## 深度定义

对于每个四耗材源集合：

```text
max_td = 四种源耗材中最高的 TD
opaque_depth = max(max_td + 1.0 mm, max_td * 1.2)
```

将 `opaque_depth` 四舍五入到实际可打印的数值。

在创建测试盘前，应在校准色板生成器中输入每个源耗材的 TD。锚点深度按单个耗材生成，而不是使用整组耗材的最大 TD：

- `1.0 mm`
- `source_td / 2 + 1.0 mm`
- `source_td + 1.0 mm`

完整混合网格应首先以 `opaque_depth` 打印。较薄深度应先用于较小的代表性子集，避免测试矩阵爆炸。

## 层高测试步骤

### 步骤 1：第一批必需层高

先只做普通模式：

- `0.08 mm`
- `0.24 mm`

普通模式下，双色、三色和四色混合应先在这两个层高生成并测量。

### 步骤 2：后续扩展

在检查步骤 1 数据后，再把普通模式扩展到：

- `0.12 mm`
- `0.16 mm`
- `0.20 mm`

然后加入 Local Z：

- `0.20 mm`
- `0.24 mm`
- `0.28 mm`

然后加入 Local Z 加直接多色求解器：

- `0.20 mm`
- `0.24 mm`
- `0.28 mm`

## 阶段 1：源耗材表征

对于每个源耗材组，输入每个物理耗材的 TD，并为每个物理耗材打印实心物理耗材锚点色板，深度为：

- `1.0 mm`
- `source_td / 2 + 1.0 mm`
- `source_td + 1.0 mm`

每个锚点色板使用以下条件测量：

- 白色背衬
- 黑色背衬

目标：

- 确认 `source_td + 1.0 mm` 是否具有足够的光学稳定性。
- 估计背衬对薄样片和厚样片的影响程度。
- 捕获每种源耗材的基准 Lab 和光谱数据。

如果白/黑背衬显著改变 `source_td + 1.0 mm` 锚点色板的结果，则该深度对于该耗材或材料族并不够光学不透明。

## 阶段 2：主要不透明混合网格

对于每个耗材组，在 `opaque_depth` 打印生成的混合网格。

包括：

- 双色混合
- 三色混合
- 四色混合

先运行步骤 1。步骤 2 的层高和模式应在检查步骤 1 数据后再打印。

目标：

- 学习在基本不受背衬影响的深度下的颜色响应。
- 非锚点混合色板只在黑色背衬上测量。
- 比较普通层堆叠、Local Z 和直接多色 Local Z。
- 判断同一名义比例在不同层高下颜色变化有多大。

## 阶段 3：深度模型子集

不要一开始就在每个深度打印完整混合网格。锚点已经包含按单个耗材 TD 生成的深度扫描：

- `1.0 mm`
- `source_td / 2 + 1.0 mm`
- `source_td + 1.0 mm`

如果在锚点数据之后仍需要混合深度建模，再在以下深度打印代表性非锚点子集：

- `1.0 mm`
- `opaque_depth / 2`
- `opaque_depth`

推荐子集：

- 所有源耗材锚点
- 所有 50/50 双色混合
- 若干偏斜双色比例，例如 `1:3` 和 `3:1`
- 每组三耗材组合中的一个平衡三色混合
- 每组三耗材组合中的一个偏斜三色混合
- 一个平衡四色混合
- 若干偏斜四色混合

目标：

- 估计深度如何影响颜色和半透明性。
- 检查颜色是否可以在薄样片、半深度样片和不透明深度样片之间插值。
- 判断完整网格是否需要额外的深度扫描。

## 阶段 4：背衬和照明子集

背衬应作为子集测试，不应立即乘到整个网格上。

使用：

- 白色背衬
- 黑色背衬

从以下样本开始：

- 锚点
- 薄深度和 TD 派生锚点深度

背光测量应作为独立实验：

- 它对于透光画、灯具和透射式零件可能很重要。
- 如果没有用单独字段标明测量几何，不应将其混入反射式侧面测量模型。
- 它需要支持透射测量的仪器，或经过校准的光谱辐照度测量系统；当前 NH9 反射式测量流程不适合该实验。

## 候选耗材组

先从一种材料族开始，例如 PLA，再考虑混合材料类型。

推荐第一批测试组：

- 高 TD CMY 加白色
- 高 TD CMY 加黑色
- 低 TD CMY 加白色
- 低 TD CMY 加黑色
- 高 TD RYB 加白色
- 高 TD RYB 加黑色
- 低 TD RYB 加白色
- 低 TD RYB 加黑色

有用的可选组：

- RGB 加白色
- RGB 加黑色
- RGB 加透明或自然色耗材
- 中性光学组：白色、灰色、黑色、透明/自然色
- 对立色组：青色、红色、黄色、蓝色
- 同一色相但不同 TD
- 相近 TD 但不同色相

荧光、丝绸、哑光、亮光、PETG、ABS 和其他特殊材料族应分开处理。它们可能具有不同的散射和表面行为。

## 颜色变化组

在获得第一批干净数据后，加入受控变化：

- 青色、品红或黄色略有差异的 CMY 组
- 红、黄或蓝偏暖/偏冷的 RYB 组
- Lab 颜色相近但 TD 不同
- TD 相近但 Lab 颜色不同

这些组用于判断模型是否可以根据测得的源颜色和 TD 泛化，还是过于依赖某一个品牌/颜色族。

## 打印板准备和打印

打印校准色板前，打印机应完成 XY 机头校准。

打印前应清洗打印板，或确认打印表面干净且没有油污、灰尘和旧胶残留。按照该板面的常规清洁方法处理，例如 PEI 使用洗洁精和水，然后完全干燥。这样可以降低附着失败、局部翘起以及底部接触不一致的风险。

开始运行前：

- 确认 XY 机头校准已经完成。
- 确认打印板清洁且干燥。
- 确认所有耗材足够干燥，可以稳定挤出。
- 确认所有卷轴 ID 与 manifest 和切片器槽位一致。
- 确认打印机中有足够材料完成整盘打印。
- 确认使用预期喷嘴、层高、材料配置和板面类型。

打印过程中和打印后：

- 在打印板安全移出打印机前，保持热床温度。
- 如果冷却释放会导致色板脱落并丢失顺序，不要让打印件在打印机上冷却释放。
- 小心移动整块打印板，并保持其平整。
- 在色板完成记录前，避免让打印板向任何方向弯曲。
- 测量前，将整盘平放保存。

如果有色板提前脱落，除非其身份和方向完全明确，否则应将该盘标记为受影响。

## 打印板存储和处理

打印后，应将打印板视为有顺序的样品托盘。

- 每块板都应与其 manifest 或盘 ID 一起保存。
- 将打印板平放在干净盒子、托盘或带标签的保护袋中。
- 避免堆叠时摩擦色板测量面。
- 避免用手指触摸测量侧面。
- 让灰尘、油污和耗材碎屑远离侧面测量面。
- 尽可能尽快测量；如果不能，应记录存储时长和条件。

如果打印板在测量前存放很久，湿度、紫外线、灰尘和表面处理都可能成为隐藏变量。

## 测量处理

测量时必须保持色板顺序。

测量前：

- 将打印板放在稳定桌面上。
- 使用蓝丁胶或等效的可移除固定方式将打印板固定到桌面。
- 确保移除色板时，打印板不会滑动、倾倒或掉落。
- 尽可能使用分光测色仪定位夹具。
- 如果使用夹具，用双面胶或其他可重复的可移除固定方式将其固定到桌面。
- 确认测量过程中夹具不会旋转或漂移。
- 如果不使用夹具，保持 NH9 位置和样品方向可重复，并尽量遮挡样品测量面周围的杂散光。
- 对于薄样片，尤其要避免样品和背衬周围受到光污染。
- 打开切片器校准页，并直接在切片器中使用 NH9 测量流程。
- 开始测量前确认 NH9 处于 `I+E` 模式：`Settings -> Sample mode`。
- 保持打印板照片和 manifest 在可见位置。

一次只测量一个色板：

1. 根据 manifest 找到下一个色板。
2. 只从板上取下这个色板。
3. 尽可能将它放入夹具，并让预期测量侧朝向仪器。如果无法使用夹具，保持同一侧面、方向、背衬和 NH9 位置尽量可重复。
4. 采集配置数量的读数。
5. 将已测色板放到带标签的完成样品区域。
6. 继续下一个色板。

不要一次取下一批松散色板。如果桌上有多个相似色板散放，顺序恢复将变得不可靠。

如果色板破损、弯曲、掉落、方向变得不明确或失去身份，应在备注中标记，而不是默默测量。

## 测量流程

对于每个打印盘：

1. 加载或生成色板 manifest。
2. 确认 manifest 记录：
   - 耗材槽位 ID
   - 源颜色
   - 源 TD 值
   - 层高
   - Local Z 模式
   - 直接多色求解器状态
   - 色板深度
   - 盘号
3. 确认 Local Z 和直接多色模式的实际切片器设置。
4. 确认 XY 机头校准已经完成。
5. 清洗并干燥打印板，或确认打印表面干净。
6. 使用致密墙设置打印。
7. 在打印板安全移除前保持热床加热。
8. 移除色板前拍摄整盘照片。
9. 平放存储和移动打印板。
10. 打开切片器校准页并连接 NH9。
11. 使用 `Settings -> Sample mode` 确认 NH9 处于 `I+E` 模式。
12. 如果可以使用夹具，测量前将打印板和夹具固定在桌面上。
13. 测量会话参考：白色背衬和黑色背衬。
14. 在白色背衬和黑色背衬上测量实心物理耗材锚点。
15. 混合耗材色板只在黑色背衬上测量。
16. 按 manifest 顺序一次测量一个色板。
17. 每个色板采集配置数量的读数。
18. 只有在完整样本组采集后才移除离群读数。
19. 保存 Lab 值和原始光谱数据。
20. 记录背衬、照明条件、打印机、喷嘴、材料族和任何打印缺陷。

## 需要保留的数据字段

每条测量记录应保留：

- Manifest 名称
- 色板 ID
- 色板类型
- 耗材槽位
- 耗材名称
- 源十六进制颜色
- 源 TD 值
- 比例计数
- 百分比
- 有效层计数
- 有效层循环
- 层高
- 混合模式
- 直接多色求解器是否启用
- 色板深度
- 背衬条件
- 会话参考测量：白色背衬和黑色背衬
- 每条测量记录的测量条件，通常为白色背衬或黑色背衬
- 锚点色板展开为白色背衬和黑色背衬两条测量记录
- 非锚点色板在黑色背衬上测量
- 测量几何，例如 NH9 反射测量的侧面 d/8
- NH9 样品模式，预期为 `I+E`
- NH9 捕获的镜面/样品模式分量
- 光源和 CIE 观察者
- Lab 读数
- 平均 Lab
- 原始光谱
- 仪器序列号/型号
- 时间戳
- 盘面位置
- 盘/运行 ID
- 卷轴 ID
- 打印板处理备注
- 存储时长和条件
- 备注和缺陷标记

## 开放问题

早期数据需要回答的问题：

- `opaque_depth` 是否能消除每种材料族的背衬影响？
- `opaque_depth = max_td + 1 mm` 是否足够，还是需要更大的倍数？
- 层高改变颜色主要是因为物理层节奏、半透明性，还是表面纹理？
- 普通模式和 Local Z 在相同名义层高下是否可比较？
- 直接多色 Local Z 是否能减少三色和四色混合中的可见条带？
- 双色/三色/四色结果是否可由源颜色和 TD 预测，还是某些颜料组合需要交互项？
- RGB 是否适合作为校准组，还是 CMY/RYB 更能代表减色式耗材混合？
- 白色和黑色更适合作为源耗材，还是作为背衬/参考条件？
- 透明/自然色耗材应作为源颜色、TD/散射控制，还是两者兼具？

## 推荐第一次运行

不要一开始就测试所有材料组。

第一次运行：

- 一个高 TD CMY 加白色组
- 一个高 TD CMY 加黑色组
- 一个低 TD RYB 加白色组
- 一个低 TD RYB 加黑色组

对于每个组：

- 在三个按单个耗材 TD 派生的深度打印锚点。
- 只打印步骤 1 的完整不透明深度混合网格：普通模式 `0.08 mm` 和 `0.24 mm`。
- 在检查步骤 1 数据后，再决定是否进入步骤 2 的层高和模式。
- 只有当第一批锚点和混合结果显示需要额外深度建模时，才打印深度模型子集。
- 锚点在白色背衬和黑色背衬上测量。
- 所有非锚点色板在黑色背衬上测量。

使用这些数据判断完整矩阵是否应扩展到更多材料族，或者是否需要先调整色板生成器/测试流程。
